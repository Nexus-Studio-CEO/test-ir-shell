## Introduction

Le projet test-ir-shell est un dépôt de test pour les fonctionnalités de base d'un shell. Il est utilisé pour tester les commandes et les fonctionnalités de base d'un shell.

## Fonctionnalités

* Test des commandes de base
* Test des fonctionnalités de gestion de fichiers
* Test des fonctionnalités de gestion de processus

## Installation

Pour installer le projet, vous devez cloner le dépôt et suivre les instructions suivantes :
```bash
git clone https://github.com/votre-nom-utilisateur/test-ir-shell.git
cd test-ir-shell
```

## Utilisation

Pour utiliser le projet, vous devez simplement exécuter les commandes suivantes :
