# Documentation du projet test-ir-shell

## Introduction
Le projet test-ir-shell est conçu pour fournir une interface de ligne de commande (CLI) pour tester et interagir avec les appareils IR (infrarouge). Ce fichier de documentation fournit une vue d'ensemble du projet, ses fonctionnalités, et comment l'utiliser.

## Fonctionnalités
- **Envoi de commandes IR** : Le projet permet d'envoyer des commandes IR à des appareils compatibles.
- **Réception de feedback** : L'interface peut recevoir et afficher les réponses ou les états des appareils après l'envoi d'une commande.
- **Sauvegarde des commandes** : Les commandes fréquemment utilisées peuvent être sauvegardées pour un accès rapide.

## Installation
1. Cloner le repository : `git clone https://github.com/votre-nom-utilisateur/test-ir-shell.git`
2. Installer les dépendances : `pip install -r requirements.txt`
3. Exécuter le script d'installation : `python setup.py install`

## Utilisation
1. Exécuter l'interface de ligne de commande : `ir-shell`
2. Suivre les invites pour sélectionner l'appareil et la commande à envoyer.
